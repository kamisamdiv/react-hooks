# React Hooks Practical Exam

This repository contains a React app with six practical exercises covering
state, effects, refs, context, memoization, and reducers.

The app and exercise details are in [`practical/`](./practical/). See
[`practical/README.md`](./practical/README.md) for the requirements, known
limitations, test steps, and run instructions.

To start the app:

```bash
cd practical
npm install
npm run dev
```
